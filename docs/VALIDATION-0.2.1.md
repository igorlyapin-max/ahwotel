# Проверка AHWOTel 0.2.1

Дата: 2026-09-13. Package `com.ahwotel`, versionCode 3, versionName 0.2.1, minSdk 26, targetSdk 36. Debug signing тем же ключом.

APK: `artifacts/AHWOTel-0.2.1-debug.apk`, 14 806 758 bytes. SHA-256: `a44c64bfa30a1652cb06d278a150613bab9822fc68dc02fd2ec890c61a47f847`. Хеш установленного `base.apk` на SM-J260F и эмуляторе совпал с этим артефактом.

## Реализованный результат

Все 22 показателя имеют по восемь разделов справки: определение, единицы/измерение, влияние, интерпретация, пример, ограничения, участие в оценке и источник. Подсказки доступны из Monitor, History, Settings и Diagnostics; общий справочник работает до первой сессии. Все тексты EN/RU включены в APK и доступны офлайн.

Выбор языка применяется к содержимому и элементам управления. Название HEADROOM переведено как «Тепловой запас». Технические коды сохраняются с локализованными пояснениями. В Diagnostics справка показывает время и результат последней проверки; History использует общие объяснения графика, не присваивая прошлым замерам текущую доступность источника.

Панель прокручивается, закрывается кнопкой или системной Back; отдельная стрелка возвращает к списку параметров. Область кнопок — 48 dp. Открытие справки не запускает сбор и не проверяет источники. Правило для будущих метрик закреплено в `AGENTS.md`; типизированное сопоставление и проверка ресурсов требуют описаний для каждой метрики.

## Особенности тестовой среды

На эмуляторе появлялся системный диалог `System UI isn't responding`, перехватывавший Back. После восстановления System UI кнопкой Wait ручная проверка Back и весь целевой набор с крупным шрифтом прошли. Код обработки Back не изменялся для обхода этой неисправности среды. Артефакты: `system-ui-anr.png`, `manual-guide-before-back.png`, `manual-guide-after-back.png` в каталоге эмулятора.

Во время разработки исправлены размер кнопок и закрытие панели без сохранения скрытого модального состояния; тесты уточнены для вкладок и содержимого именно открытой панели. Готовность подтверждена конечными сценариями, а не наличием элементов в дереве UI.

После проверки шрифт эмулятора возвращён к 100%, эмулятор завершён. Другие OEM, формальная аудиторская проверка TalkBack и production signing не входили в эту итерацию. APK использует прежний debug key. Commit/push не выполнялись.

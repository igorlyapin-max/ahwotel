# Samsung: установка и проверка AHWOTel 00.00.00.02 (code11)

Дата проверки: 2026-09-13. Устройство: Samsung SM-J260F, Android 8.1 / API 27. Проверен основной APK из Git-поставки `v00.00.00.02`, commit `beaf48665be1d859bd298107846ab9b452accb6b`.

## Native-проверки

Успешно проверены 20 отдельных сценариев на устройстве:

- профили Battery-only и Self-only для обоих вариантов старого флага `BATTERY`, сохранение через UI и фактический сбор;
- три CSV-экспорта после пересоздания Activity, включая выбранные сессию и период OEM;
- все семь регрессий таймера;
- три сценария Battery/Self: рабочий сборщик, независимость настроек, русский help и временный debug-контекст батареи;
- Back для обоих языков и родительских экранов, интервалы OEM, учёт screen-off pause и локализованные графики;
- Basic/временный Verbose, истечение срока и structured logs в JSONL, Logcat, stdout/stderr.
- OTLP: 1000 пакетов, 100 ответов HTTP 503, повторная доставка, не более двух незавершённых задач, ранняя отправка готового пакета при наличии отложенного, восстановление расписания, смена endpoint и отключение экспорта.

`artifacts/code11-focused-samsung.txt` содержит три успешных сценария и два неуспешных: OEM-кнопка не была создана LazyColumn вне видимой области маленького экрана; OTLP ожидал сетевое условие. В тесте OEM добавлена прокрутка контейнера к кнопке перед нажатием, без изменения кода приложения. После пересборки тестового APK все 16 сценариев `artifacts/code11-regression-samsung.txt`, включая OEM, прошли. После подключения Wi-Fi отдельно прошёл OTLP-тест. Это 20 отдельных успешных сценариев с учётом повторных проверок, а не один полностью успешный общий прогон. Сводка: `artifacts/code11-native-samsung-summary.json`.

Первоначальная проверка OTLP завершилась по timeout 240 секунд: `Active default network: none`, все 1000 тестовых пакетов ожидали `NetworkType.CONNECTED`. После подключения Wi-Fi неизменённый `UploadAcceptanceTest#backlogRetriesStayBoundedAndFutureDeadlineCanMoveEarlier` прошёл на Samsung за 36,616 секунды (`OK (1 test)`). Проверены не менее 1100 HTTP-вызовов, ограничение до двух незавершённых задач, приоритет готового пакета перед отложенным, идемпотентное восстановление расписания, очистка очереди и отмена задач при смене endpoint/отключении OTLP. Тест использует локальный HTTPS mock server с тестовым доверием к сертификату, не внешний коллектор; production TLS не изменялся.

Повторный тест выполнялся только в `com.ahwotel.acceptance`; обе APK и target instrumentation проверены helper-скриптом. Основной процесс `com.ahwotel` сохранил PID `12626`, активную сессию, настройки, installation identity и все строки из снимка непосредственно перед тестом. Базовые замеры выросли со 169 до 204; foreground service остался активным. Доказательства: `artifacts/code11-network-1789323815/instrumentation.txt`, `result.json`, `main-services.txt`, снимки `artifacts/code11-main-network-{before,after}-1789323815`.

После теста открыт основной AHWOTel: подтверждены «Идёт сбор», прежний ID сессии, «Непрерывно до остановки» и «Локально · отправка выключена». Доказательство — `main-final-ui.xml`, флаг `mainUiRunning` в `result.json`. Первоначальный `am start -W` ожидал за экраном блокировки и завершился с `Status: timeout`; после снятия экрана блокировки отдельно подтверждены фокус MainActivity и видимые элементы приложения. Таймаут команды запуска не используется как доказательство успешного открытия.

На момент установки часы Samsung оставались в 2018 году, `auto_time=1`. Перед подключением сети отмечен риск синхронизации времени и последующей очистки старой истории по retention. При следующем подключении этот риск реализовался; результаты проверки ниже. Новое доказательство overhead ≤5% и лицензированная среда Knox не заявляются.

## Смена даты перед повторным OTLP-тестом

При восстановлении USB 2026-09-13 телефон уже показывал 2026 год, `auto_time=1`, активную Wi-Fi сеть. Сбор основного приложения продолжался с прежними PID `12626`, ID сессии и настройками. До запуска повторного теста сделана копия базы: старые данные 2018 года уже отсутствовали. По сравнению с последним снимком после установки удалены 33 завершённые сессии, 7828 базовых замеров и 7068 записей Battery/Self. Это соответствует очистке по текущей дате и сроку хранения; тест ещё не запускался. Настройки телефона, часы и данные основного приложения через ADB при этом не изменялись.

Снимок `artifacts/code11-main-verify-1789323072-2` содержит эти старые строки; повторная проверка резервной БД через `PRAGMA integrity_check` — `ok`. Согласованные снимки момента обновления также сохранены в `artifacts/code11-main-stopped` и `artifacts/code11-main-installed`. Восстановление на телефон не выполнялось. Доказательство сравнения: `artifacts/code11-network-1789323815/clock-history.json`. Сохранность во время последующего теста проверяется относительно нового снимка `artifacts/code11-main-network-before-1789323815`; она не означает сохранности удалённой до теста истории 2018 года.

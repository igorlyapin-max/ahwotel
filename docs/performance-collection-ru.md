# Сбор производительности и пауза при блокировке

В code31 пропуск замера отделён от завершения сессии. Пауза повторно проверяется перед каждым плановым чтением и внутри OEM worker. Начатый синхронный вызов может завершиться; пауза не останавливает сессию. Flush при блокировке сохраняет буфер без нового опроса runtime-показателей. Доверенный сохранённый management envelope v1 позволяет выполнить release с большей revision; настройки v1 остаются неподдерживаемыми. Несохранённый черновик Settings переживает Activity recreation.

AHWOTel собирает CPU, RAM, хранилище/I/O, нагрев, батарею и накладные расходы агента. Модель, аппаратная платформа, сборка Android, версия агента, сеть и доступность источников служат контекстом сравнения. Инвентаризация приложений, счётчики пакетов, отслеживание установки/удаления, состояние безопасности и административные политики больше не собираются и не отображаются. Разрешения `QUERY_ALL_PACKAGES` и `KNOX_APP_MGMT` не запрашиваются.

«Настройки → Поведение сбора → Не собирать, пока устройство заблокировано» по умолчанию выключено. Проверяется текущий экран блокировки Android, включая блокировку свайпом, а не наличие PIN/пароля. Сбор приостанавливается при выполнении этого ограничения либо независимого ограничения по выключенному экрану. Таймер сессии продолжает работать. Накопленные данные можно сохранять и отправлять. После разблокировки допустимые потоки возобновляются в той же сессии с новыми базовыми интервалами и сегментами графиков.

Формат deployment profile версии 2 включает `pauseWhenLocked`; отдельный MDM-ключ — `pause_when_locked`. Профили версии 1 требуется пересоздать. Локальные настройки мигрируют без сброса параметров производительности. Старая непрофильная история остаётся в Room до штатного retention, но исключается из интерфейса и новых экспортов. При первом запуске обновления однократно очищается очередь OEM: готовые пакеты могут содержать исключённые показатели. Остальные потоки отправки и локальная история сохраняются.

Ручная приёмка без перезагрузки: запустить непрерывный сбор с разрешённым выключенным экраном и паузой по блокировке; заблокировать устройство, включить экран без снятия блокировки. Все потоки остаются на паузе. Разблокировать и проверить возобновление той же сессии без скачков CPU/I/O и задержек планировщика, включающих паузу. Повторить сочетания настроек и завершение ограниченной сессии по таймеру во время блокировки.
